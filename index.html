Predicting Atmospheric CO₂ — Time Series Analysis of the Mauna Loa Record

MAT 482: Data Analysis · University of Southern Mississippi

Analyzed 67 years (March 1958–February 2025) of monthly atmospheric CO₂ data from the NOAA Mauna Loa Observatory and forecasted the next 12 months using a sequence of increasingly refined models in R.

Methodology:

  • Built a quadratic regression with 11 monthly seasonal dummy variables to capture the accelerating upward trend and annual "breathing" cycle
  • Applied AR(11), ARIMA(3,1,3), and SARIMA grid search to residuals, progressively removing autocorrelation
  • Evaluated all models using a scale-independent prediction quality metric Q
  • Best model (Regression + ARIMA(3,1,3)) achieved Q = 100.0000% on the held-out validation set, with a maximum monthly error of just 0.53 ppm
  • SARIMA grid search confirmed seasonal dummies had already handled all periodic structure

Web-Based Python Framework for Plant Disease Detection

Group Project · University of Southern Mississippi · School of Computing Sciences

Full-stack ML application enabling farmers to detect crop diseases early by uploading leaf photos, receiving a real-time diagnosis powered by a ResNet-50 deep learning model.

My contributions:

  • ResNet-50 Model Design & Literature Review — Benchmarked architectures, justified ResNet-50 selection based on prior work achieving 98–99% accuracy on PlantVillage-style datasets. Explained skip connections and residual blocks enabling effective deep training.
  • Transfer Learning Pipeline — Applied ImageNet-pretrained weights, fine-tuned a custom classification head (2048→512→22 classes) using the Adam optimizer with L2 regularization, ReduceLROnPlateau scheduling, and early stopping (patience=7).
  • Full Training Loop — Trained over 30 epochs on an NVIDIA RTX 2060 (~2.5 hrs). Monitored per-epoch train/val loss and accuracy; best checkpoint saved at epoch 28 with val loss 0.0652.
  • Training Performance — Rapid convergence: 83.9% validation accuracy by epoch 1 (transfer learning effect), surpassing the 85% target by epoch 2, reaching 98.3% validation accuracy at epoch 28.
  • Test Suite Validation — All 34 unit tests passed across dataset, inference, and training modules (runtime: ~6 min).
  • Dataset & Preprocessing — Used the Kaggle Plant Leaves dataset (4,494 images, 22 classes, 11 species). Applied data augmentation (random flips, color jitter) to reduce overfitting.
  • Final Model Performance — 99.71% test accuracy on 696 held-out images; macro F1 = 1.00; only 2 minor confusions (Chinar & Jatropha diseased/healthy variants).
